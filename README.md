
# Healthcare Data Cleaning and Analysis Using SQL

## Project Overview
This project demonstrates data cleaning and exploratory data analysis using MySQL.

## Dataset
Healthcare patient records dataset.

## Data Cleaning Tasks
- Removed duplicates
- Converted date columns from txt to date
- Handled NULL and BLANK values
- Standardized data formats

## Analysis Performed
- Admissions by year
- Most common medical conditions
- Prevelance of Medical consitions(disease) among particular age group
- Billing amount by year, insurance provider
- Rolling total billing amount by year, insurance provider 
- Patient demographics

## Tools Used
- MySQL
- MySQL Workbench

- data_cleaning.sql
- data_analysis.sql
